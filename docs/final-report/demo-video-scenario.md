# 데모 영상 시나리오

## 1. 데모 목표

Smart Edu Platform의 주요 학습 흐름을 짧은 영상 안에서 연결해 보여준다. 데모는 실제 사용자 관점에서 회원가입, 학습 계획, AI 보조, 집중 기록, 커뮤니티, 친구 소통, 보상, 협동 기능, 접근성, 관리자 점검 흐름을 순서대로 확인하는 방식으로 구성한다.

## 2. 권장 데모 흐름

### 2.1 소개페이지 인트로

- 웹 첫 진입 시 입자 기반 인트로 표시
- 수학 기호/학습 용어 입자가 민트 연필과 `사각사각` 텍스트로 형성되는 장면 확인
- 인트로 종료 후 랜딩 화면으로 전환
- 필요 시 `인트로 다시 보기` 버튼으로 재생 확인

### 2.2 회원가입/로그인

- 회원가입 화면에서 아이디, 닉네임, 비밀번호 validation 확인
- 로그인 후 대시보드 진입
- 잘못된 로그인 입력 시 오류 안내 확인

### 2.3 대시보드

- 오늘 일정, 진행 중 퀘스트, 집중 기록 요약 확인
- 진행 중 퀘스트 더보기/숨기기 흐름 확인

### 2.4 일정/칸반

- 일정 생성 또는 기존 일정 확인
- D-Day와 칸반 task 상태 변경
- 복습 알림 설정 안내 흐름 확인

### 2.5 AI 학습 추천

- AI 학습 화면 진입
- 질문 입력 후 응답/fallback 표시 확인
- 요약, 오답 분석, 대화방 흐름을 간단히 보여줌
- 외부 AI 호출 실패 시 fallback 응답이 표시되는 점을 설명

### 2.6 집중/통계/히트맵

- 집중 타이머 또는 집중 세션 기록 확인
- 주간 통계와 히트맵 intensity 확인
- 짧은 기록은 연한 색, 긴 기록은 진한 색으로 표시되는 흐름 설명

### 2.7 커뮤니티

- 게시글 목록에서 카드/표 보기 확인
- 게시글 상세 overlay 진입
- 좋아요/싫어요, 북마크, 신고 버튼 확인
- 댓글 작성 또는 댓글 목록 확인
- 작성자 공개 프로필 이동 흐름 확인

### 2.8 친구/쪽지 실시간 반영

- 친구 요청 목록 확인
- 친구 요청 수락/거절 흐름 확인
- 친구 접속 상태와 쪽지 thread 확인
- 가능하면 두 브라우저 세션에서 실시간 업데이트를 확인

### 2.9 보상/포인트 상점

- 포인트 보유 상태 확인
- 상점 아이템 구매/적용
- 프로필 꾸미기와 칭호 반영 확인

### 2.10 레이드/협동 퀘스트

- 협동 퀘스트 목록, 참여, 기여도 추가, 진행률 확인
- 사용자별 숨김/보관 또는 나가기 흐름 확인
- 보스 레이드 파티 목록, 상세, 진행률 확인

### 2.11 접근성 돋보기/전체 읽기

- 접근성 설정 화면 진입
- 텍스트 크기, 고대비, 모션 감소 옵션 확인
- 돋보기와 전체 읽기 동작 확인

### 2.12 관리자 점검/정지 사유

- 관리자 계정으로 관리자 화면 진입
- 점검 모드 ON/OFF와 공지 발행 확인
- 계정 정지 사유가 사용자 제한 화면에 반영되는지 확인

## 3. 실패하기 쉬운 부분과 대체 시나리오

| 구간 | 실패 가능성 | 대체 시나리오 |
|---|---|---|
| 외부 AI 응답 | API key 또는 quota 제한 | fallback 응답 표시를 설명하고 mock 기반 자동 테스트 결과를 제시 |
| WebSocket 실시간 반영 | 네트워크 또는 배포 환경 제한 | HTTP fallback으로 목록을 새로고침해 상태 변화 확인 |
| 보스 레이드 숨김/탈퇴 | 참여자별 서버 저장 정책 미완성 | 후속 Issue #389로 분리된 설계 과제로 설명 |
| seed 데이터 | demo DB 상태가 다를 수 있음 | seed 적용 완료 결과와 기본 demo 계정 기준 화면을 사용 |
| 접근성 음성 기능 | 브라우저 권한 제한 | 텍스트 설정, 돋보기, 전체 읽기 UI 흐름 위주로 시연 |

## 4. 촬영 전 체크리스트

- 최신 main 배포 상태 확인
- demo seed 적용 여부 확인
- 민감정보가 화면이나 콘솔에 노출되지 않는지 확인
- 관리자/demo 계정 준비
- 브라우저 캐시와 세션 상태 정리
- 모바일 viewport 또는 반응형 화면 확인
- 실패 시 설명할 fallback 화면 준비
