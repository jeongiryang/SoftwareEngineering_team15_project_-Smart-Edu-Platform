## 1. 최종 선정 주제

- 선정 주제: **주제 1. 개인화된 학습 관리 앱**

### 선정 이유

- 다양한 연령대와 학습 목적을 포괄할 수 있음
- 시스템 확장성이 높음
- 실제 학습 앱 사용 경험에서 발생하는 불편함을 해결할 수 있음
- 주제 4의 AI 추천 시스템과 실제 구현 요소가 일부 유사하다고 판단됨
- 조원 전체 선호도와 투표를 통해 최종 결정함

## 2. 제외한 주제와 이유

### 2.1 주제 2. 환경 모니터링 대시보드

- 완성도를 높이기 위해서는 실제 IoT 기기 기반 테스트가 필요하다고 판단함
- 조원 모두 테스트 가능한 IoT 기기를 보유하고 있지 않음
- 따라서 현실적인 구현 및 검증이 어렵다고 판단하여 제외함

### 2.2 주제 3. 헬스케어 트래커

- 웨어러블 기기와 삼성헬스 연동 가능성을 검토함
- Android Studio Java 기반 데이터 import 방식도 조사함
- 그러나 삼성헬스 앱에 대한 의존성이 큼
- 삼성헬스 앱이 설치되어 있지 않은 경우 정상 작동이 어려움
- 기존 삼성헬스 앱과의 뚜렷한 차별점을 만들기 어렵다고 판단하여 제외함

## 3. 요구사항 분석 방식

사용자가 실제로 느끼는 불편함과 요구사항을 반영하는 것이 중요하다고 판단하여, 인터뷰와 설문조사를 핵심 요구사항 도출 기법으로 선택함.

### 핵심 기법

- 인터뷰
- 설문조사

### 보조 기법

- 문서 분석
- 워크샵
- 애자일 접근법
- 사용자 스토리 및 시나리오 작성
