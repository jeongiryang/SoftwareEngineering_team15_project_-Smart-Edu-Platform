## 2. 주요 논의 내용

### 2.1 개인별 `.env` 및 Neon branch 운영

- 각자 개인 Neon branch 기준으로 `src/backend/.env`를 구성하기로 함.
- 카카오톡에서 개인별 env 설정을 공유했으나, 회의록과 GitHub 문서에는 실제 비밀값을 기록하지 않기로 함.
- `.env`에는 `DATABASE_URL`, `DIRECT_URL`, `JWT_SECRET`, `PORT`, `CORS_ORIGIN`, `AI_API_KEY` 키가 필요함.
- `production` DB는 최종 배포용이므로 로컬 개발에서 사용하지 않기로 함.
- `dev-main`은 팀 통합 개발과 migration 기준 branch로 사용하고, 개인 개발은 개인 branch에서 진행하기로 함.

### 2.2 PR #41 이후 개인 branch migration 적용

- PR #41 merge로 dev-main 기준 Prisma 초기 migration이 반영됨.
- 각자 개인 Neon branch에도 동일한 migration을 적용해야 함을 공유함.
- 안내된 기본 흐름은 main 최신화 후 backend에서 Prisma migration, generate, validate를 실행하는 방식임.
- `migrate dev` 실행 중 새 migration 생성, DB reset 관련 문구가 뜨면 진행하지 않고 공유하기로 함.
- Issue #40을 DB branch, `.env`, migration 운영 기준 문서로 활용하기로 함.

### 2.3 Prisma 5.22 유지 여부와 Prisma 7 전환 검토

- 초기에는 Prisma 5.22 기준으로 세팅을 진행함.
- 팀원들이 Prisma update 안내를 확인하면서 최신 버전 사용 여부를 논의함.
- Prisma 7에서는 `schema.prisma` 내부 `url`, `directUrl` 방식이 변경되고, `prisma.config.ts`, `.env` 명시 로딩, PostgreSQL adapter가 필요함을 확인함.
- 단순 업데이트가 아니라 주요 설정 구조가 바뀌는 major update임을 인식함.
- 기능 구현이 본격적으로 쌓이기 전에 전환 가능성을 실험해보는 방향으로 정리함.
- main은 건드리지 않고 별도 브랜치에서 Prisma 7 전환을 검증하기로 함.

### 2.4 Prisma 7 전환 적용 및 세팅 가이드 정리

- Prisma 7 전환 검증 후 PR #44를 통해 Prisma 7 기준 설정을 main에 반영함.
- Prisma 7 기준으로 `schema.prisma`는 datasource provider만 유지하고, 실제 연결 설정은 `prisma.config.ts`와 `.env`에서 관리하기로 함.
- 애플리케이션 runtime은 `DATABASE_URL`, Prisma CLI/config는 `DIRECT_URL`을 사용하기로 정리함.
- PostgreSQL/Neon 연결은 `@prisma/adapter-pg`, `pg` 기반 adapter를 사용함.
- 공용 Prisma Client는 `src/backend/src/utils/prisma.js`를 통해 사용하기로 함.
- DB smoke test로 `npm run test:db`를 추가함.
- Prisma Client 생성 누락 시 `@prisma/client` 관련 오류가 발생할 수 있어, `npx prisma generate` 단계를 Issue #45와 README에 반영하기로 함.

### 2.5 팀원 로컬 세팅 확인

- 기존 Prisma 5.22 세팅을 완료한 팀원들도 Prisma 7 전환 후 main 최신화와 backend 의존성 재설치를 다시 진행해야 함.
- 기본 순서는 다음과 같음.
  - main 최신화
  - `cd src/backend`
  - `npm install`
  - `npx prisma generate`
  - 루트에서 `npm run check`
  - 개인 dev branch 확인 후 `npm run test:db`
- `test:db` 실행 시 SSL 관련 warning이 표시될 수 있으나, 테스트가 PASS이면 현재 단계에서는 정상으로 보기로 함.
- Issue #45를 Prisma 7 전환 후 팀원 로컬 세팅 가이드로 사용하기로 함.
